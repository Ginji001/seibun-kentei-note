# 化粧品成分検定1級 学習ノート（公開版）

ビルド不要・外部CDN不要の日本語PWAです。2026年12月13日の試験に向けた計画、問題記録、成分の整理、間違いノート、模試記録、直前暗記、バックアップに対応しています。学習開始日と週あたりの学習時間は設定で変更できます。

このアプリは**非公式の学習ツール**です。学習ヒントは公式テキストで確認してください。記録はこの端末・ブラウザの IndexedDB にだけ保存され、サーバーには送信されません。別端末へ移すときは設定からバックアップを書き出して読み込みます。

## ローカルで開く

リポジトリのルートで次を実行し、表示された URL をブラウザで開きます。

    python3 -m http.server 8000

index.html をファイルとして直接開く方法ではなく、ローカル HTTP サーバーを使ってください。オフライン利用には、一度オンラインで Service Worker の準備を済ませます。

## GitHub Pages

GitHub のリポジトリ設定で Pages の公開元を対象ブランチのルートに設定します。ビルド手順は不要です。公開 URL は https://ginji001.github.io/{リポジトリ名}/ です。PWA の manifest とアセット参照はリポジトリ配下で動く相対パスです。

## データと更新

記録の保存先は公開版専用の IndexedDB public-seibun-notebook です。Service Worker のキャッシュも public- で始まる専用名を使います。同期機能はありません。新しい版を公開すると、アプリ起動時に Service Worker が更新を確認して画面を読み直します。

tests/ には画面・保存・バックアップ・オフライン・日付・レイアウトの確認用スクリプトがあります。ブラウザ自動テストは Node.js と Puppeteer または Playwright、Chrome を別途用意して実行してください。
